Code and public reproducibility materials for object-detection-based prediction of treatment-record-defined pulp involvement in primary molar deep-caries periapical radiographs.

Study Task
This project evaluates three object-detection architectures for localizing and classifying the tooth-crown-plus-pulp-chamber region of interest (ROI) in primary molar periapical radiographs with deep caries.

The labels are defined according to retrospective clinical treatment records combined with 12-month postoperative follow-up outcomes:

fill: pulp-not-involved, corresponding to teeth treated with restorative treatment only, with no clinical or radiographic abnormalities throughout follow-up.

rct: pulp-involved, corresponding to teeth treated with pulpotomy or root canal therapy, with no signs of treatment failure throughout follow-up.

These labels are treatment-record-defined surrogate labels and should not be interpreted as histological pulp-status labels. Although histological examination is the ideal gold standard, the use of clinical treatment outcome combined with follow-up status as the reference standard is a widely adopted and feasible approach in comparable studies.

The ROI is defined as the smallest rectangular box that encompasses the entire tooth crown and pulp chamber. Given the thin enamel and large pulp chamber of primary teeth, carious lesions and the pulp chamber frequently overlap on two-dimensional radiographs; annotating the crown-and-pulp-chamber region as a single ROI therefore avoids missed annotations.

Public Data Materials
The original pediatric clinical radiographs are not included in this repository. The images were obtained from clinical records of minors at a community health service center, and unrestricted public deposition is not permitted under the current ethics approval and institutional data-governance requirements.

To support reproducibility, this repository provides:

Aggregate dataset statistics.

Test-set class distribution and confusion-matrix counts.

Model performance metrics.

A synthetic/example dataset matching the independent test-set class distribution.

The synthetic/example dataset is intended only for testing the code pipeline and file format. It is not a clinical image dataset and must not be used for diagnostic model validation.

Installation
Python 3.7 is recommended, consistent with the software environment reported in the manuscript (PyTorch 1.8, CUDA 11.2, cuDNN 8.2.1).

bash
pip install -r requirements.txt
For GPU training, install a PyTorch build that matches your CUDA version. See the official PyTorch installation instructions if needed. The manuscript hardware configuration was an Intel Core i5-7500 CPU with an NVIDIA GTX 1080Ti GPU (16 GB VRAM).

YOLOv7-X is trained through the official implementation, which must be cloned separately:

bash
mkdir -p external && cd external
git clone https://github.com/WongKinYiu/yolov7.git
cd yolov7
pip install -r requirements.txt
# Download the official pretrained weights (used as the transfer-learning starting point)
wget https://github.com/WongKinYiu/yolov7/releases/download/v0.1/yolov7x.pt

Basic Usage
The main training/evaluation script is:

bash
python code/step3_train_det.py
The script trains and evaluates three detectors in sequence:

Faster R-CNN (ResNet50-FPN), initialized from COCO pretrained weights.

SSD300-VGG16, initialized from COCO pretrained weights.

YOLOv7-X, trained through the official repository with yolov7x.pt as the pretrained starting point.

All models are trained with transfer learning from ImageNet/COCO pretrained weights.

Input data format

This repository uses the PASCAL VOC format:

text
data/VOCdevkit/tooth/
├─ JPEGImages/     # *.jpg / *.png, uniformly resized to 620×480
└─ Annotations/    # same-name *.xml files generated by LabelImg
On first execution, step3_train_det.py automatically scans the VOC directory and generates detection_index.csv containing:

image_path: path to the radiograph or synthetic example image.

xml_path: path to the corresponding VOC XML annotation file.

label: fill or rct.

subgroup: maxilla or mandible, inferred from the file-name prefix.

Subgroup inference rule: file names beginning with P are assigned to maxilla; file names beginning with M are assigned to mandible. If your naming convention differs, modify code/step3_dataset_det.py::infer_subgroup.

The public synthetic dataset can be used to verify file loading and preprocessing, but it is not intended to reproduce the clinical performance values reported in the manuscript.

The test prediction files generated by the script include:

Hard predicted labels (top-1 box class per image).

Confidence scores for the top-1 box per image.

Ground-truth class per image.

These outputs can be used for mAP/AP, confusion-matrix, Wilson confidence-interval, and bootstrap F1 confidence-interval calculations.

Training Configuration
All three models use a unified training configuration:

Parameter	                    Value
Optimizer	                    SGD (momentum = 0.9, weight decay = 5e-4)
Initial learning rate	        0.001
Learning-rate schedule	      Cosine annealing
Number of epochs	            150
Batch size	                  16
Early stopping	              Terminate when validation loss does not decrease for 15 consecutive epochs
Data augmentation	            Random horizontal flip (p = 0.5), random rotation (±15°), brightness/contrast adjustment
Pretraining	                  ImageNet / COCO pretrained weights for transfer learning
Data augmentation is applied only to the training set, after dataset splitting, to avoid information leakage. The validation and test sets are only resized to 620×480 without augmentation.

Evaluation Metrics
Model performance is assessed using the following metrics:

① Detection accuracy metrics

Precision = TP / (TP + FP)

Recall = TP / (TP + FN)

Average Precision (AP): area under the Precision-Recall curve

Mean Average Precision (mAP): mean of the per-class AP values

F1 score = 2 × (Precision × Recall) / (Precision + Recall)

② Efficiency metrics

Inference speed (FPS, frames per second)

Parameter count (Params, millions)

Computational complexity (FLOPs, gigafLoats)

③ Confusion matrix

The TP, TN, FP, and FN counts of each model on the test set are recorded to assess the specific error types.

Reproducibility Notes
Random seed in the training script: 42 (set for Python, NumPy, and PyTorch).

Models evaluated: YOLOv7-X, Faster R-CNN, and SSD.

Test-set size reported in the manuscript: 103 images.

Test-set class distribution: 66 fill images and 37 rct images.

Dataset splitting: 8 : 1 : 1, using stratified random sampling according to the fill/rct class proportion.

Splitting was performed at the patient level to ensure that teeth from the same patient did not appear in more than one subset. Because each patient contributed only one periapical radiograph in this study, patient-level and image-level splitting were equivalent.

The dataset split CSVs are saved under output/results_<timestamp>/split_*.csv for reproducibility.

Statistical Analysis
The performance of each model was comprehensively evaluated using multiple quantitative metrics on the independent test set:

95% CIs for accuracy, precision, and recall were calculated using the Wilson score method, based on the test-set confusion-matrix counts.

95% CIs for the F1 score were estimated using bootstrap resampling of the test-set classification results (1000 resamples, with replacement).

mAP and AP are reported as point estimates only, without 95% CIs, because the archived test-output files contained binary predicted labels and summary AP values but did not contain the raw prediction confidence scores required for valid CI estimation.

Comparative analysis among models was conducted by ranking the metric values obtained on the independent test set and by jointly interpreting the 95% CIs of the corresponding metrics.

This reporting approach is consistent with common practice in comparable studies comparing deep-learning models.

Subgroup Analysis
To evaluate the adaptability of the models to different anatomical positions, subgroup analyses were performed separately for maxillary primary molars and mandibular primary molars.

The subgroup analysis is primarily descriptive: the mAP and F1 scores of each model in the maxillary and mandibular groups are compared directly, and the consistency of performance across anatomical positions is examined.

The script writes the subgroup results to:

text
output/results_<timestamp>/<ModelName>_subgroup.csv

Data Availability Statement
The source code for preprocessing, model training, evaluation, confidence-interval calculation, and statistical analysis is provided in this repository. The original radiographic dataset cannot be publicly released because it consists of clinical dental radiographs from pediatric patients. Although direct personal identifiers were removed during data processing, the images are derived from hospital clinical records of minors, and the current ethics approval (Approval No. 2025-Y-047-D) and institutional data-governance policy do not permit unrestricted public deposition of the original images or a representative raw-image subset.

To support reproducibility while protecting patient privacy, aggregate dataset statistics, the test-set class distribution and confusion-matrix counts, and a synthetic/example dataset matching the test-set class distribution are provided.

Access to the original de-identified data may be considered only upon reasonable request, subject to approval by the corresponding institution and ethics committee and completion of an appropriate data-use agreement.
